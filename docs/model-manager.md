# Integrated model manager

The first read-only stage is available at /nippey-print-models. Select an existing housing revision to automatically open its first STL attachment or open a local STL without uploading it. The standalone assignment prototype remains available. The viewer is a dependency-free WebGL preview with depth testing and all valid triangles, not a CAD viewer; bounding dimensions use all valid triangles and STL has no declared units. Existing attachments are accessed through Frappe's normal file URLs.

Future component types define inherited geometry parameters per product. A standard cover inherits none of the housing geometry parameters; special covers inherit relevant geometry. Component revisions and housing compatibility are independent. Historical filenames remain unchanged. No component import or release is performed by this stage.
