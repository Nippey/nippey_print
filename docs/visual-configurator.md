# Visual product configurator (planned)

Internal order entry first; optional customer-facing configurator later, with explicit authorization and no exposure of internal costs or CAD files. SVG rendering is independent of Inventor. Reference: [fence light sketch](fence-light-concept.svg).

Standard fence light: fixed 60 x 40 mm post. Light positions front (mesh side), rear, double. Standard overhang approximately 17 mm includes mesh and retaining strip; short 0 mm; both are presets for a freely configurable nonnegative decimal overhang in mm, including for standard posts. Front/rear short variants remain distinct because of drilling tab position. Hole 0 (none), 57 mm (Camas), or custom. ASA colors RAL 7016, 9005, 9006 and other available ASA. Neutral white LED with removable warm-white filter as standard. Double uses two LEDs, PETG covers and filters, one terminal. Separate special product definition for nonstandard post dimensions because cover and filter geometry change. Visualizer should respond to parameters, show hole/tab and lit sides, surface color, and label dimensions. Concept only, not CAD or dimensional proof. Export Inventor files manually with review; optional API later.

Technical data model first; typed parameter validation, canonical geometry signatures, duplicate prevention, immutable released revisions, file SHA256 verification, release workflow and BOM mapping are follow-up tasks before production use.

## Special fence light geometry (design discussion)

Special posts: no screw-hole option; no semantic front/back/left/right. For a post wider than the LED footprint, offer a rectangular bounding box, straight convex hull (rubber band), concave or convex connecting curves. Curved connections are constructed using tangency to the post geometry; no user-adjustable curvature strength. LED placement may be centered, aligned to either edge of a side, or diagonal at a post corner. The LED footprint is square; no rotation parameter is offered. Use a local coordinate system for free placement; exact coordinate conventions and tangent construction rules still need agreement. Multiple adjacent or opposed LEDs may initially use a manual configuration with notes; do not assume geometry or BOM for these. Preserve standard configuration names as editable suggestions, e.g. ZL-STD-V-Ü17-B0-WW-7016. Special product preset currently remains provisional; existing configurations must not be silently migrated.

Approved visual reference: [four outer contours](fence-light-contours.svg). The sketch illustrates the contour families, not exact tangent CAD curves or dimensions.
